Responsive and accessibility verification limits
-------------------------------------------------
The stylesheet contains a 760px single-column breakpoint, 44px mobile action
buttons, a keyboard skip link, visible :focus-visible outlines, and reduced-motion
handling. The UI uses semantic headings, sections, buttons, status text and an
aria-live result area. Visual viewport checks (mobile/desktop), screen-reader
testing and interaction with a live populated gateway remain unverified: the
Computer Use browser inventory had no browser provider, and its Chrome binding
stopped because it could not determine the current URL with enough confidence.
No screenshot or claim of visual verification is made.

No performance benchmark was run for this UI task; it adds no benchmark claims.
Gateway metrics are process-local and cumulative, so horizontal replicas do not
produce a fleet aggregate in this dashboard. The single-flight gate and cooldowns
are also process-local; a public multi-replica deployment needs shared or
ingress-level action throttling in addition to the per-invocation 64-request cap.
